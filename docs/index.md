# Classy-O 80

An 8-digit desk calculator for iPhone and iPad, rebuilt key for key: truncating rather than
rounding, strictly left to right, with the percent key, independent memory and COST / SELL / MAR
of the desktop unit it copies.

- [Support and how the less obvious keys work](support)
- [Privacy policy](privacy)

Requires iOS 18 or later.
